# 热身教练 · 原生微信小程序

零服务器、零维护的微信小程序版热身教练。

## 上线步骤（3 步）

### 1. 注册小程序账号

访问 https://mp.weixin.qq.com/ → 注册 → 选择「小程序」→ 完成认证 → 获取 **AppID**

### 2. 配置 AppID

打开 `project.config.json`，将 `YOUR_APPID_HERE` 替换为你的 AppID：

```json
"appid": "wx1234567890abcdef"
```

### 3. 上传发布

1. 下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开 → 导入项目 → 选择 `warmup-coach-miniapp-native` 目录
3. 填入 AppID → 确定
4. 点击「上传」按钮 → 填写版本号（如 1.0.0）
5. 登录 https://mp.weixin.qq.com/ → 「版本管理」→ 提交审核
6. 审核通过后点击「发布」

**分类建议**: 选择「工具 → 健康」或「体育运动」
